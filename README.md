# Palindrome Checker Application (Java)

## 📌 Project Overview

The **Palindrome Checker Application** is a Java-based project that demonstrates different programming approaches to check whether a word, string, or number is a palindrome.

A **palindrome** is a sequence that reads the same forward and backward.

Examples:

* madam
* level
* racecar
* 121

This project contains **13 different use cases** implemented using various **Java concepts and data structures** such as loops, methods, recursion, stacks, queues, and linked lists.

## 📖 Use Cases Implemented

### Use Case 1 – Basic Palindrome Check

Checks whether a string is a palindrome using a simple comparison approach.

### Use Case 2 – StringBuilder Method

Uses **StringBuilder reverse()** method to verify palindrome.

### Use Case 3 – Loop Based Palindrome

Reverses the string using a **for loop** and compares it with the original string.

### Use Case 4 – Method Based Palindrome

Implements palindrome logic inside a **separate method**.

### Use Case 5 – Case Insensitive Palindrome

Checks palindrome ignoring **uppercase and lowercase differences**.

### Use Case 6 – Ignore Spaces Palindrome

Handles palindromes with **spaces removed**.

Example:

```
nurses run
```

### Use Case 7 – Stack Based Palindrome

Uses **Stack data structure** to reverse and compare characters.

### Use Case 8 – Recursion Palindrome

Checks palindrome using **recursive function calls**.

### Use Case 9 – Number Palindrome

Checks whether a **number is a palindrome**.

Example:

```
121
1331
```

### Use Case 10 – User Input Palindrome

Accepts **input from the user** and checks palindrome dynamically.

### Use Case 11 – LinkedList Palindrome

Uses **LinkedList data structure** to verify palindrome.

### Use Case 12 – Queue Palindrome

Uses **Queue data structure** for palindrome comparison.

### Use Case 13 – Advanced Palindrome Validation

Handles **special characters, spaces, and case normalization**.

Example:

```
A man, a plan, a canal, Panama
```
